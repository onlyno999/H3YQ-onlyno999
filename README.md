# H3YQ-onlyno999 · 音频驱动 Agent

用**源片原声**驱动人物对口型演出的专用生产 Agent（YQ＝音频驱动线）。

- **触发**：用户给一段带对白的视频/音频＋1–2 张人物照片，说「音频驱动 / 声音驱动 / 用这个声音驱动他们演」。
- **硬定义**：驱动音频必须从源视频提取原声、原样使用——绝不重新生成、绝不 TTS 合成。
- **云端工作流**：RunningHub 2106642679642812418《H3官流（单采极速文戏）》；映射：提示词 138.value｜时长 132.value｜画幅 115｜种子 129｜图槽 137/139｜**音频驱动入口 148.audio（唯一一路、驱动型）**。
- **固定收尾**：出片不带音轨，交付前把驱动原音一字不改回挂（详见 SKILL.md 第 6 节）。
- **验证案例**：《喜剧之王》海边对白 0–6s 双人驱动（27 RH 币、四句起音误差 ≤0.06s、用户 ❤️ 认可），全档案在 `references/case_2026-10-04_king_of_comedy.md`。

目录：`SKILL.md`（Agent 全规程）｜`references/`（案例档案＋工作流普查）｜`scripts/`（实测派发脚本，凭据只走环境注入）。
