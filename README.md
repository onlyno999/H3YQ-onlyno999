# H3YQ-onlyno999 · 音频驱动 Agent

用**源片原声**驱动人物对口型演出的专用生产 Agent（YQ＝音频驱动线）。

- **触发**：用户给一段带对白的视频/音频＋1–2 张人物照片，说「音频驱动 / 声音驱动 / 用这个声音驱动他们演」。
- **硬定义**：驱动音频必须从源视频提取原声、原样使用——绝不重新生成、绝不 TTS 合成。
- **云端工作流**：RunningHub **2101416149702504449**（MiniMax H3 Ref2VA · 双时钟 STABLE 4v4a；2026-10-04 替换旧线 2106642679642812418）；映射：提示词 **79.prompt**｜时长 73.value｜画幅 78｜种子 62｜图槽 72/101｜**音频驱动入口 74.audio**。红线：84 合流出口永不传值（传值出片没音轨）、123/124/125 是生图支线不碰。
- **出片特性**：音画同出、自带原声音轨（与驱动原声互相关 0.998），交付前验音轨即可，一般不必回挂（详见 SKILL.md 第 6 节）。
- **验证实测**：新线图谱与双测实证在 `references/workflow_2101416_map.md`（6s 双人对白测试：验脸 PASS、口型逐音节驱动、音轨 0.998，用户评「非常完美」拍板替换）。
